# Apex Launcher


Apex Launcher is an Android launcher project designed to provide a modern and customizable experience for Minecraft: Java Edition on Android devices.

Features

- Modern and clean user interface
- Minecraft: Java Edition launch support
- Configurable game versions and settings
- Graphics renderer compatibility, depending on device and configuration
- Performance customization options
- User-friendly controls and settings

Requirements

- Compatible Android device
- Android 8.0 or later, depending on the final build configuration
- Required Minecraft game files and a valid account where applicable
- Internet connection for downloads and online services

Building the Project

Development Requirements

- Android Studio
- Android SDK
- Compatible JDK
- Gradle build system

Open the project in Android Studio, allow Gradle synchronization to complete, and build the APK using the configured build variant.

Project Status

Apex Launcher is under development. Features, supported Minecraft versions, and device compatibility may change as development progresses.
